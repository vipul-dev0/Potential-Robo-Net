Quick overview

One robot node. One remote system. One autonomous loop.

01

Sensor Data

NodeMCU powered robot hardware captures ultrasonic distance and other device metrics for safe operation.

02

Remote Control

Operators can send movement instructions from a running application and monitor the robot in real time.

03

Autonomous Mode

The backend can evaluate sensor input and trigger movement decisions without waiting for manual input.

How it works

From ultrasonic readings to intelligent decision making

1. Capture

Robot hardware reads the distance using the HS-SR04 sensor.

2. Transmit

Data is sent to the web backend through the NodeMCU communication layer.

3. Decide

The app checks conditions and chooses whether to respond manually or autonomously.

4. Act

The platform issues movement commands or updates the status for the device.
